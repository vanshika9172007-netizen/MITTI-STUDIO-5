
# Mitti Studio – Class & Booking Management Dashboard

A responsive dashboard for managing pottery classes, student enquiries, bookings, and enrollment analytics.

## Features
- Dashboard overview with summary statistics
- Pottery class schedules
- Student enquiry records
- Student search and status filters
- Enrollment analytics chart
- Responsive design for mobile and desktop

## Technologies Used
- HTML5
- CSS3
- JavaScript
- JSON

## Project Structure
```text
MITTI-STUDIO4/
├── src/
│   ├── index.html
│   ├── dashboard.html
│   ├── css/
│   ├── js/
│   └── data/
│       ├── classes.json
│       └── enquiries.json
├── README.md
└── performance-report.md
```

## How to Run
1. Open the project folder in VS Code.
2. Run `src/index.html` using Live Server.
3. Open `src/dashboard.html` to access the dashboard.

## Note
This project uses sample JSON data for demonstration purposes. It is not connected to a live database.
